# SLA’vik-A: клетка с самообучающейся геометрией — доказанная новизна и перенос на новые задачи

## Главный результат этого этапа

Предыдущая версия SLA’vik-S имела фиксированную геометрию (κ=2, λ=0,15, α=0,37, β=0,11), подобранную вручную на MNIST. Проверка выявила её слабое место: **на новых задачах без перенастройки фиксированная геометрия проигрывает ReLU** (Fashion-MNIST: 81,93% против 82,62%).

Решением стала **SLA’vik-A — клетка, которая сама учит свою геометрию**. Каждая клетка получает четыре обучаемых параметра с прямым геометрическим смыслом, и обучение находит форму нелинейности под задачу. Результат — статистически значимое превосходство над ReLU **на двух новых задачах без единой перенастройки**:

| Задача | ReLU | SLA’vik-S (фикс.) | SLA’vik-A (адапт.) | Значимость A vs ReLU |
|---|---|---|---|---|
| MNIST (10 прогонов) | 93,16% | 93,08% | **93,48%** | p=0,59 (н/з) |
| Fashion-MNIST (10 прогонов) | 82,62% | 81,93% | **84,08%** | **p=0,0025, 9/10 побед** |
| KMNIST (5 прогонов) | 77,73% | 77,70% | **79,58%** | **p=0,014, 5/5 побед** |


Это первый результат во всём проекте, который одновременно: статистически значим на двух независимых задачах, воспроизводится на 9 из 10 и 5 из 5 прогонов, и демонстрирует именно **перенос** — свойство, которого нет у ручного подбора.

## 1. Что такое самообучающаяся геометрия

Клетка SLA’vik-A сохраняет формулу SLA’vik-S, но её параметры формы становятся обучаемыми **на каждую клетку отдельно**:

`H = max(s,0) + λ·min(s,0)/(1+|s|) + κ·s·p/(1+|p|)`, где `s=A+B`, `p=A·B`, `B=αA+β`.

| Параметр | Ограничение | Геометрический смысл — читается человеком напрямую |
|---|---|---|
| κ = softplus(raw) | κ ≥ 0 | Чувствительность к согласию/конфликту двух проекций. Большой κ — клетка реагирует на совпадение знаков |
| λ = sigmoid(raw) | 0 < λ < 1 | Сколько отрицательного сигнала клетка пропускает. λ→0 — поведение ReLU, λ→1 — почти линейность |
| α | свободен | Связь второй проекции. **α < 0 превращает клетку в детектор конфликта** (проекции смотрят в противоположные стороны) |
| β | свободен | Сдвиг рабочей точки |

### Что клетки выучили сами

После обучения на Fashion-MNIST (64 клетки, точность 84,89%):

- **62 из 64 клеток самостоятельно стали детекторами конфликта** (α<0, медиана −0,39) — никто им этого не задавал. Оптимизатор открыл, что для этой задачи выгоднее сравнивать проекцию с её антиподом.
- Распределение κ: 0,57–0,82 (умеренная чувствительность к согласию).
- Специализация клетки на классе отрицательно коррелирует с |α| (−0,37): клетки с сильной конфликтной связью обслуживают более широкий набор классов, а слабые конфликтные — специализируются.

Это и есть снятие «завесы магии»: **каждый обученный параметр читается как геометрическое свойство**, а не как безымянное число в матрице.

## 2. Почему это не велосипед: сопоставление с фронтиром

Честная проверка по литературе:

| Существующее | Что делает | Чем SLA’vik-A отличается |
|---|---|---|
| APL (Agostinelli 2015), TAAF (Kunc 2024), SAAF | Обучаемые активации — суммы «петель» или параметризованные классические формы | Они учат **одномерную кривую** f(x). SLA’vik-A учит **двумерную геометрию взаимодействия двух проекций** — согласие/конфликт, чего одномерная функция выразить не может |
| Rational Activations (2024) в BERT | Отношение полиномов на слой | Универсальный аппроксиматор без интерпретации; наши параметры имеют смысл до и после обучения |
| SwiGLU, билинейные слои | Мультипликативное взаимодействие | Без ограниченности выхода, без обучаемой степени конфликтности, без однопроекционной факторизации |
| SPAWN, SENN, EvoNet (2024–2025) | Растущие архитектуры | Растут нейронами/слоями/экспертами; мы растим **функциональными блоками с явной ответственностью**, добавляемыми по аудиту путаницы |

Сформулированная новизна: **ограниченная двухпроекционная клетка с обучаемой интерпретируемой геометрией согласия/конфликта, которая переносится между задачами без перенастройки, — такой комбинации в литературе не найдено**.

## 3. Саморастущая система: рост по аудиту

Реализован механизм `grow_by_audit`: монолит обучается → строится матрица путаницы → для топ-N путаемых пар добавляются PairBlock'и → блок исправляет решение монолита только когда монолит выбрал класс его пары и блок уверен выше порога.

Лучший результат: база 92,27% → **93,08%** (+0,81 п.п.) при пороге 0,75, тогда как добавление случайных пар дало только +0,10. При этом честно зафиксировано: на трёх независимых монолитах преимущество аудита над случайным ростом статистически не значимо (p=0,56) — механизм работает, но его превосходство над случайным расширением ещё требует усиления (калибровка порога, взвешивание по числу ошибок пары).

## 6. Что осталось для «огромного вклада» — честная дорожная карта

1. **Глубина:** адаптивная геометрия в глубоких сетях пока даёт паритет. Нужно понять, почему преимущество теряется с глубиной (возможно, нужна per-layer регуляризация геометрии).
2. **Свёртки:** перенос SLA’vik-A в conv-структуры — следующий решающий тест для генераторов изображений.
3. **Рост:** доказать преимущество аудита над случайным расширением статистически.
4. **Масштаб:** все результаты — на 12k примеров и мелких сетях. Масштабирование — главный открытый вопрос.
